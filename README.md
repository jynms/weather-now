# 🌤 Weather Now

A weather application that uses browser geolocation to retrieve and display real-time weather information based on the user's current location.

## Project Background

Developed during my junior high school years while exploring web development with HTML, CSS, and JavaScript. This project was one of my first experiences working with browser APIs and real-time data from external services.

## Features

- Detects user location using the Geolocation API
- Displays real-time weather information
- Shows current temperature and feels-like temperature
- Displays humidity and wind speed
- Weather condition descriptions with icons
- Converts coordinates into a readable location

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API
- OpenStreetMap Nominatim API
